# Student Performance Analytics

A Python data analysis project built with NumPy.

## Overview

Student Performance Analytics analyzes student grades across
multiple subjects and generates statistical reports.

## Features

- Load student data from CSV files.
- Calculate mean, median, maximum and minimum scores.
- Calculate standard deviation.
- Calculate individual student averages.
- Rank students based on performance.
- Analyze average scores by subject.
- Calculate pass and fail statistics.
- Detect statistical outliers using the IQR method.
- Run automated unit tests.

## Technologies

- Python
- NumPy
- CSV
- unittest
